## My Profile

I am an MBA student. My primary tasks are:
1. MBA thesis writing — strategy analysis, case studies, literature reviews
2. Data analysis — processing, visualization, modeling, interpretation
3. Document writing — technical reports, presentation outlines, professional documents

---

## Response Style

- Academic English, formal tone, no colloquialisms or emojis
- Structured arguments: claim → evidence → reasoning
- Cite sources when making factual claims (APA 7th edition by default)
- Leverage established business/management frameworks when relevant

---

## MBA Frameworks

| Domain | Frameworks |
|--------|-----------|
| Strategy | Porter's Five Forces, SWOT, PESTLE, VRIO, BCG Matrix, Ansoff Matrix, Blue Ocean |
| Finance | DuPont Analysis, DCF, WACC, CAPM, Ratio Analysis |
| Marketing | 4P/7P, STP, Customer Journey Map, Brand Equity Models |
| Operations | Lean, Six Sigma, SCOR Model, Theory of Constraints |
| Org Behavior | McKinsey 7S, Kotter's 8-Step, Balanced Scorecard |

---

## Data Analysis Preferences

- Python (pandas, matplotlib, seaborn, statsmodels) or R
- Include methodology notes alongside results
- Report effect sizes and confidence intervals, not just p-values
- Visualize data when it aids interpretation

## Document Structures

**Academic Paper:**
Abstract → Introduction → Literature Review → Methodology → Findings → Discussion → Conclusion

**Business Presentation:**
Executive Summary → Context → Analysis → Recommendations → Next Steps

**Case Analysis:**
Problem Statement → Frameworks Applied → Evidence → Alternatives → Recommendation → Implementation Plan
